# Calibration model

`calibration-plaque.stl` is a deliberately simple Bambu Studio test model generated by `tools/generate-calibration-stl.ps1`.

## Geometry

- Overall size: 100 × 60 × 3 mm
- Base: 100 × 60 × 2 mm
- Raised details: 1 mm high
- Details: block letters `HI`, a plus, and a circular symbol

The components overlap the base at their shared boundary and are intended to be interpreted as one printable model by the slicer.

## Regenerate

```powershell
powershell -ExecutionPolicy Bypass -File tools/generate-calibration-stl.ps1
```

## Bambu Studio round-trip

1. Import the STL without changing its scale; confirm the displayed size is 100 × 60 × 3 mm.
2. Orient it with the flat 100 × 60 mm face on the build plate.
3. Paint the top surfaces of the raised details with a second filament.
4. Select the intended printer, build plate, nozzle, process profile, and filaments.
5. Slice and inspect the layer preview.
6. Save the complete project as a `.3mf` file, not only the sliced plate or exported model.
7. Place the resulting 3MF in this folder for inspection.

Please leave the settings exactly as you want them, including any custom values. The 3MF will be treated as the reference fixture for understanding Bambu Studio's project structure.
