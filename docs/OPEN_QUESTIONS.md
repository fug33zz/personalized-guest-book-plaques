# Open questions

## Physical product

- What are the exact book dimensions, spine position, cover material, and usable front-cover area?
- Will there be one book model or several sizes and colours?
- What printer, nozzle, slicer, materials, and colour-change capability will be used?
- What is the maximum acceptable print time and material cost per plaque?
- Which adhesive works safely and reliably on the supplier's cover?
- Is the plaque fitted by staff or shipped for the customer to fit?

## Catalogue and customization

- Which event types launch first?
- Which fields exist in each template, and what are their maximum lengths?
- Which languages and accented characters must be supported?
- Which fonts are licensed for commercial use and web embedding?
- Can clients select dimensions, or are dimensions fixed by book model?
- How many colour combinations should be offered?

## Order workflow

- Is the editor part of a new storefront or embedded in an existing website?
- Does the first release require checkout and payment?
- Is staff approval required before production?
- What production output is required: STL, 3MF, SVG, DXF, or another format?
- Should production files be generated automatically or prepared by staff from an order specification?
- Where should customer designs and personal data be stored, and for how long?

## Brand and hosting

- What product/brand name and domain should the site use?
- Which logo, typography, brand colours, and tone should be used?
- Is GitHub Pages suitable for the public prototype, or is an application host needed once accounts, orders, or server-side generation are introduced?
