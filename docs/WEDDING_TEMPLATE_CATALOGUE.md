# Wedding template catalogue

The wedding collection contains ten composition-led templates. Decorative geometry is integrated into each layout instead of being treated as generic clip art. The only optional ornament is the approved heart; customers may also choose no ornament.

## Eligibility behaviour

- Each template exposes only fonts and borders approved for its composition.
- Heart and No ornament are the only customer-selectable ornament values.
- Compatible choices survive a template change; incompatible choices become the new template default.
- Older four-template designs migrate to the nearest supported composition.
- Legacy rings, stars, and generic botanical selections migrate to the template default.
- The same shared primitive definitions drive the SVG preview and generated 3MF geometry.

## Production status

All ten examples generate sanitized two-colour Bambu 3MF projects with the provisional profile. Automated inspection confirms a single tool change at the first raised-detail layer, no painted mesh faces, top ironing, the 0.2 mm nozzle profile, and removal of account metadata.

Dimensions, minimum strokes, clearances, and final material combinations remain provisional until physical book and print testing resumes.
