# Project brief

## Background

The business rents photobooths for events and wants to offer personalized guest books for the photographs created at those events. A supplier will provide plain guest books. The business will produce a custom 3D-printed plaque and glue it to the front cover, turning the standard book into a unique keepsake.

## Product

The physical product is a flat plaque printed as one complete object, including its base, lettering, and decorative details. It is not a collection of separately aligned letters.

The intended visual language is premium and celebratory: a dark base with contrasting raised typography and optional decorative motifs. The supplied reference includes wedding, birthday, and retirement examples.

## Customer experience

The online experience should eventually allow a client to:

1. Select a tested template.
2. Edit permitted text and options within defined constraints.
3. See a trustworthy preview.
4. Receive clear feedback when content does not fit or cannot be manufactured.
5. Submit or purchase the approved design.

The first product may use a small number of constrained templates. A more flexible editor remains an option, but is not yet a decision.

## Business goals

- Add a high-perceived-value personalized product to photobooth bookings.
- Keep design and production time predictable.
- Prevent customers from creating fragile or unprintable designs.
- Make ordering simple for non-technical users.
- Build a reusable system that can support more event types and book formats later.

## Initial scope

- One-piece rectangular plaques with rounded corners
- Controlled text fields and decorative elements
- Tested font, size, spacing, colour, and layout combinations
- Web preview appropriate for customer approval
- Documented manufacturing rules

## Explicitly undecided

- Template-only editor versus flexible layout editor
- Exact plaque and book dimensions
- Printer technology, nozzle size, layer height, and materials
- Single-colour, filament-change, or multi-material production
- Adhesive and cover compatibility
- Whether the site handles payment or only design submission
- Production file generation and approval workflow

## Success criteria for the first release

- A customer can personalize a design without design software.
- Every accepted configuration conforms to tested manufacturing limits.
- The preview accurately represents text, placement, colours, and proportions.
- Staff can turn an order into a production-ready file with minimal manual work.
- The plaque survives normal handling and remains securely attached to the book.
